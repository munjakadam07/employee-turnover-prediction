# Employee Turnover Prediction using Logistic Regression

## Project Overview
This project builds a Machine Learning model to predict whether an employee is likely to leave the company. The goal is to help organizations reduce attrition and improve employee retention strategies.

## Problem Statement
Employee turnover can increase recruitment costs and reduce productivity. This project uses Logistic Regression and Regularization techniques to predict employee attrition based on multiple workplace factors.

## Dataset
The dataset contains 900 employee records with features such as:

- Job Satisfaction
- Performance Rating
- Years at Company
- Work-Life Balance
- Distance from Home
- Monthly Income
- Training Hours
- Annual Bonus
- Employee Role
- Department

Target Variable:
Employee_Turnover  
(1 = Employee Left, 0 = Stayed)

## Models Implemented
1. Baseline Logistic Regression
2. Logistic Regression with L1 Regularization (Lasso)
3. Logistic Regression with L2 Regularization (Ridge)
